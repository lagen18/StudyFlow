# StudyFlow

StudyFlow is an application designed to help university students manage their classes and assignments in one place. It supports students who may miss deadlines or important updates because course information is scattered across multiple websites. Its features include collecting assignment deadlines, prioritizing tasks by urgency, and sending notifications about assignments, class cancellations, and classroom changes. By bringing this information together, StudyFlow aims to save users approximately three hours of repetitive work each week.
