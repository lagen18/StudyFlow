# StudyFlow Features

- **Deadline Collection:** Gather assignment deadlines from different course websites in one place.
- **Task Prioritization:** Organize assignments by urgency so students can identify what to complete first.
- **Assignment Reminders:** Send notifications about upcoming assignment deadlines.
- **Class Cancellation Alerts:** Notify students when a scheduled class is canceled.
- **Classroom Change Alerts:** Notify students when the location of a class changes.
