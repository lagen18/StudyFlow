# Go-to-Market and Launch Checklist

## First users

I would invite the first 50 TUJ students through class group chats where project sharing is allowed. I would ask whether entering assignments is easy and whether the priority list helps them plan their week.

## Value proposition

StudyFlow puts assignments from different courses in one list so students can see what is due next.

## Before launch

- [ ] Merge the finished work into `main`.
- [ ] Test adding, editing, completing, and deleting assignments.
- [ ] Check that overdue, current, and future deadlines are sorted correctly.
- [ ] Test reminders with browser notifications allowed and blocked.
- [ ] Check that assignments remain after refreshing the page in the same browser.
- [ ] Check the site on phone and desktop screens, including Chrome and Safari.
- [ ] Explain that the first version does not sync data between devices or import from course websites automatically.

## Launch day

- [ ] Deploy the latest `main` branch to GitHub Pages.
- [ ] Open the public URL and repeat the basic assignment and reminder tests.
- [ ] Share the link with the first group of students.
- [ ] Record bugs and suggestions in GitHub Issues for the next update.
