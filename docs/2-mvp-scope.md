# MVP Scope and Feature Backlog

## Product vision

StudyFlow is designed to help university students keep assignments for different courses in one place and avoid missing deadlines.

## Launch goal

My goal is to launch a basic web version by December 15, 2026. Students will be able to enter assignments from their course websites and keep them organized in one list.

## Must have for the first version

1. Deadline collection: Students can enter an assignment name, course, and due date in one list. Automatic importing from course websites can come later.
2. Task prioritization: StudyFlow sorts unfinished assignments by due date and highlights overdue or soon-due tasks.
3. Assignment reminders: The dashboard shows upcoming deadlines when a student opens the app. If the student allows browser notifications, the app can also send reminders while it is open.

## Later versions

4. Class cancellation alerts: This needs a reliable source of class announcements, so I will add it after the basic assignment tools work.
5. Classroom change alerts: This also depends on accurate school updates and can wait until a later version.

The first version focuses on the problem discussed in my README: course information is scattered across different websites, which makes deadlines easy to miss.
